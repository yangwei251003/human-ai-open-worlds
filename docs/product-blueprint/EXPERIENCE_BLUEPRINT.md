## 体验原则

| 原则 | 可观察行为 | 禁止模式 |
|---|---|---|
| 同一身份，七个世界 | 姓名/品牌、导航顺序、档案编号、焦点环和返回入口一致 | 七个互不相认的微站 |
| 灰度仍可分辨 | 每页至少在空间模型、排版、媒体容器、主交互、动效中的四项不同 | 只换配色、同款卡片 |
| 证据先于宣言 | 项目展示问题、本人工作、AI 协作和结果/占位 | 空泛“热爱/赋能/颠覆” |
| 动效解释层级 | 每页一个主空间隐喻、一个主交互、一个动态高潮；所有长动作可中断 | 六套效果同页争抢、不可跳过演出、无稳定参照物 |
| 移动端同等级 | 竖屏重构镜头、构图与手势，保留空间主线和动态高潮 | 因设备类型自动改为静态列表 |
| 占位也诚实 | 每个缺失资产有状态、替换键、比例和 alt | 假数据、假链接、坏图 |

## 共享 Brand DNA

- 临时签名：`YOUR NAME / AI BUILDER`，只从集中数据读取。
- 档案编号：`P-01`、`H-01`、`J-01`、`V-01`、`G-01`。
- 小面积品牌信号色 `#ff6b4a` 贯穿当前项、编号或焦点，不覆盖页面主调色。
- 语气：第一人称、具体、诚实、有过程；英文只用于短标签、编号和技术词。
- 导航始终按首页、项目、荣誉、履历、日志、影像、照片排序；当前页使用文字 + 形状 + `aria-current`。

## 布局、组件与状态

- 断点重点：360、390、768、1024、1440；Hero 与 3D 宿主使用稳定 `100dvh`、安全区和专属触摸布局。
- 共享组件：SkipLink、WorldNav、BrandMark、AssetBadge、MediaPlaceholder、Dialog/Lightbox 基础、EmptyState、Footer。
- 页面只拥有一个主空间引擎；静态内容保持 Server Component，运行时与场景位于明确 Client 边界。
- 所有筛选器必须有“全部”、空结果说明和清除方式。
- 真实链接缺失时渲染不可交互的“待补充”，不使用 `href="#"`。
- 对话框 Esc 关闭、焦点回触发器；灯箱提供前后按钮和当前位置文本。

## 交互与动效

| 触发 | 动画/反馈 | 可中断/返回 | 触摸/键盘等价 | reduced-motion | 质量自适应 |
|---|---|---|---|---|---|
| 首次进入页面 | 世界主题 Loader 显示真实进度，DOM 先到，空间层渐进组装 | 新输入接管当前状态；可跳过引导 | 内容、导航立即可读可点 | 保留静态空间构图，不自动飞行 | 先轮廓，再纹理/阴影/后处理 |
| Portal 导航 | 相机沿曲线飞入门户，背景与目标页连续变形 | 滚轮、触摸、Esc、返回、导航均立即中断 | DOM 门户按钮触发同一路径 | 短淡化切页 | DPR/粒子/采样动态调整，主隐喻不变 |
| 对象检查/聚光/翻页 | GSAP 时间线驱动对象重排、灯光或纸张层级 | 任何动作超过约 500ms 均可抢占；History 逐层返回 | 按钮、方向键和触屏手势等价 | 去除大位移/长 pin，状态瞬时可达 | 降低不可感知成本，不换成列表 |
| Cinema 选片 | 海报材质变为银幕，用户主动播放后才加载视频/音频 | 退出立即暂停并挂起纹理；返回先退播放层 | 原生 video 控制、字幕、文字稿 | 海报 + 原生播放器 | 视频按选择加载，影院资产分阶段 |
| Resume 打印 | 动态模块折叠归档后进入系统打印 | 折叠可跳过；打印时停止全部动画 | 显式按钮 | 直接打印态 | 打印 CSS 与 GPU 无关 |

GSAP 是滚动、长时间线和 3D 的唯一写入者；Motion 只管局部布局与微交互，同一属性不得双写。Lenis、ScrollTrigger 和 R3F 共享单帧时钟；不自动播放有声内容。默认是完整高强度版本，`prefers-reduced-motion` 与用户手动开关是主动安全入口，不是设备类型降级。

## 空间运行时契约

- 生命周期固定为 `mount → preload → enter → pause/resume → exit → dispose`；路由离开、标签页隐藏和媒体后台必须暂停。
- 全站导航始终位于 Canvas 之上；背景 Canvas 默认不吞触摸，页面保留 `pan-y pinch-zoom`。
- 每页保存滚动、相机、筛选与选中项；返回恢复上下文而不是重播整段开场。
- 加载顺序：HTML/导航 → 低成本空间轮廓 → 主材质 → 远景/后处理；相邻场景空闲预取，视频只在选择后加载。
- WebGL 失败、上下文丢失或关闭 Canvas 时，品牌化 DOM 海报和全部核心入口仍可操作。

## 无障碍与适配

- 首个可聚焦元素为“跳到主要内容”；`main` 有稳定 ID。
- 导航在每页保持相同相对顺序，满足 WCAG 3.2.3；聚焦不自动跳转。
- 可见焦点环至少 2px，并与相邻颜色有足够对比；交互目标视觉/点击区域不小于约 44px。
- Tab 顺序与视觉阅读顺序一致；核心功能不依赖 hover。
- 证书有文字说明；照片有具体 alt；视频有字幕/文字稿字段；装饰 SVG `aria-hidden`。
- 200% 文本缩放与 360px 宽度不遮挡；无非预期横向滚动。
- 自动持续动画超过 5 秒可暂停；避免高速前进和高速旋转同时发生，用户控制阶段不叠加自动漂移。

## 体验验收

1. 灰度截图且移除媒体后，七页仍能由空间和排版在 3 秒内区分。
2. 从任一页不回首页也能到达其他六页，并明确当前位置。
3. 仅用键盘可完成 ACT-001 至 ACT-007；关闭详情后焦点归位。
4. reduced-motion 下页面内容与功能不丢失。
5. 360/768/1440 视口无内容遮挡、坏图、hover-only 操作或不可达控件。
6. 打印 `/resume` 时导航、装饰和按钮隐藏，内容黑白清晰。
7. 移动端保留七页各自空间隐喻与动态高潮，背景 Canvas 不阻断滚动和双指缩放。
8. 路由往返 20 次后只存在一个 Canvas，场景 RAF/监听器不叠加，GPU 资源计数不持续增长。
