## 三个方向

| 维度 | A 单一电影宇宙 | B 七个独立微站 | C 统一多世界（选定） |
|---|---|---|---|
| 核心情绪 | 强统一、沉浸、品牌化 | 每页极端自由、像不同作品 | 探索感与可信度并存 |
| 字体/比例 | 一套 Display/Sans/Mono | 每页完全独立 | 页面独立排版，CJK 正文与导航语义共享 |
| 色彩/材质 | 近黑电影质感贯穿 | 无共同色彩/材质 | 页面主配色独立，小面积信号色/编号贯穿 |
| 构图/密度 | 统一稀疏电影构图 | 无规则 | 门户、工作台、博物馆、印刷、期刊、影院、暗房 |
| 动效语法 | 滚动叙事为主 | 每页任意技术 | 每页一个空间隐喻与主动态，共享中断/质量/导航运行时 |
| 适合/风险 | 易维护但违背“完全不同” | 最惊艳但迷失、重复与 CSS 泄漏风险高 | 最符合任务；需要严格 Brand DNA 与共享组件 |

## 选定方向

采用 C“统一多世界”（`DEC-001`），并由 `DEC-006` 升级为 Spatial Edition。灰度辨识规则确保差异不是换色；固定导航、BrandMark、档案编号、焦点和数据源确保访客仍知道身处同一个人的网站。

七个记忆点固定为：Hero 穿越门户、Projects 拖入检查台、Honors 穿越展厅、Resume 折叠成简历、Journal 封面展开、Cinema 海报变银幕、Gallery 底片显影。即使四页采用 R3F，也分别服务于拓扑、建筑、放映和实例化照片场，不共享“漂浮卡片 + 粒子背景”的廉价模板。

明确拒绝通用紫蓝 AI 渐变、七页同款圆角卡、随机发光球、廉价玻璃拟态、不可中断转场、多个 Canvas、多个滚动权威和“桌面 3D / 移动静态列表”。视觉强度通过材质、镜头、构图、灯光、排版和对象操作共同产生，而不是无限叠加后处理。
