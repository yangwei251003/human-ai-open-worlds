## 风险

| ID | 风险 | 概率/影响 | 缓解 | 触发器 | 状态 |
|---|---|---|---|---|---|
| RISK-001 | 七种风格破坏网站整体认知 | 中/高 | 固定导航顺序、品牌签名、档案编号、焦点语义和返回入口 | 用户迷失或页面像不同站点 | Mitigated |
| RISK-002 | 高强度动效损害阅读、方向感或可访问性 | 中/高 | DOM 等效入口、动画可中断、稳定参照物、用户主动 reduced motion、声音默认关闭 | 键盘路径断裂、眩晕或无法跳过演出 | Mitigated |
| RISK-003 | 占位内容被误认成真实履历 | 中/高 | `placeholder/ai-generated/real` 状态、显式标签、无伪造指标/链接 | 搜索摘要或卡片出现虚假事实 | Mitigated |
| RISK-004 | 七页形成维护孤岛 | 中/高 | 共享内容源、共享无障碍组件，每页最多 1–2 个独有交互 | 同一内容多处硬编码 | Mitigated |
| RISK-005 | 静态导出误用服务器功能 | 低/高 | 不使用 Server Actions/Cookies/ISR；构建门禁检查 `out/` | build 报动态功能错误 | Mitigated |
| RISK-006 | 多场景造成重复 RAF、GPU 内存泄漏或移动掉帧 | 中/高 | 单 Canvas、单滚动时钟、首次交互激活空间运行时、路由拆包、场景生命周期、资源 dispose、PerformanceMonitor 自适应 | 路由往返资源持续增长或帧率跌破门槛 | Mitigated |
| RISK-007 | Canvas 捕获触摸导致移动端滚动/缩放失效 | 中/高 | 背景 Canvas 不截获事件；原生 pan-y/pinch-zoom；仅封闭交互区接管手势 | 页面锁死、地址栏跳动或双指缩放失效 | Mitigated |
