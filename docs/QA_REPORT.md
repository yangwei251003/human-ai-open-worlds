## 无障碍验收

- 已对七条路由分别执行桌面与手机 Axe 审计，共 14 组扫描；WCAG A/AA violations 为 0。
- Gallery 远侧胶片卡片已退出可交互序列，`target-size` incomplete 已清零。
- 全站导航支持键盘打开、焦点圈定、Esc 关闭与触发器焦点回归。
- 项目、荣誉、文章、影院与照片详情均支持 Esc 关闭、焦点回归及浏览器历史记录恢复。
- Resume 标签页具备标签与面板关联语义；Cinema 保留文字稿路径，并为后续真实视频字幕轨预留数据字段。
- 用户主动选择减弱动态，或系统启用 `prefers-reduced-motion` 时，空间运行时和滚动行为会切换到可控模式。
- 主要交互控件满足 44px 触摸目标；移动端 Hero 保留原生纵向滚动与双指缩放，并只在明确水平手势后接管拖动。

## Lighthouse 性能基线

最终优化后以同一台本地设备、静态生产导出和 Lighthouse 12.8.2 默认移动端实验条件连续测量三次，采用中位数作为交付基线。3D 场景、后期效果和移动交互没有删减；空间运行时改为首次指针、触摸、滚轮或键盘交互时激活，激活后跨页面持续存在。

| 指标 | Run 1 | Run 2 | Run 3 | 中位数 |
|---|---:|---:|---:|---:|
| Performance | 78 | 93 | 92 | **92** |
| Accessibility | 100 | 100 | 100 | **100** |
| Best Practices | 100 | 100 | 100 | **100** |
| SEO | 66 | 66 | 66 | **66** |
| FCP | 1.07 s | 0.93 s | 0.93 s | **0.93 s** |
| LCP | 3.49 s | 3.18 s | 3.15 s | **3.18 s** |
| TBT | 502 ms | 76 ms | 133 ms | **133 ms** |
| CLS | 0 | 0 | 0 | **0** |
| Speed Index | 3.08 s | 1.95 s | 2.05 s | **2.05 s** |
| 首屏传输体积 | 385.7 KB | 385.7 KB | 385.7 KB | **385.7 KB** |
| 主线程工作 | 3.00 s | 1.67 s | 1.85 s | **1.85 s** |

Run 1 的冷启动 CPU 波动明显，因此不以最好或最差单次值代替中位数。SEO 66 来自下述有意保留的 noindex 上线门禁；它不是把占位身份公开索引后的预期生产分数。

## SEO 上线门禁

当前 `robots` 禁止抓取、sitemap 为空、canonical 与人物结构化数据不输出，是因为真实姓名和生产域名尚未配置。这是防止占位身份被索引的预期保护，不是 SEO 缺陷。配置真实身份、公开内容和生产域名后，应重新生成 sitemap、canonical、Open Graph 信息与适用的结构化数据，再执行一次线上 SEO 验收。
